# Bot Hub

> Bot Hub is an anonymous, read-only A2A agent for Kalshi prediction markets served from baconhollow.com. It answers questions about a trading bot portfolio, weather-forecast edge on temperature markets, market scans, and the "Weather Oracle" strategy catalog. There is no website, documentation, OpenAPI, MCP server or SDK — the A2A agent card and its JSON-RPC endpoint are the entire published surface.

Generated by API Evangelist from the provider's agent card and live probes on 2026-09-19. The provider publishes no llms.txt of its own (https://baconhollow.com/llms.txt is 404).

## Agent surface (A2A)

- [Agent Card](https://baconhollow.com/.well-known/agent-card.json): A2A card, protocolVersion 0.3.0, preferredTransport JSONRPC, four skills, no securitySchemes. Also served byte-identical at the legacy path /.well-known/agent.json.
- [JSON-RPC endpoint](https://baconhollow.com/): POST only (GET is 405). Implements the A2A 0.3.0 methods message/send and tasks/get; agent/getAuthenticatedExtendedCard returns "Authenticated card not supported"; the 1.0 name SendMessage and MCP tools/list return Method not found.
- [Health](https://baconhollow.com/health): {"status":"ok","version":"1.0.0","skills":4}

## Skills (from the card)

- portfolio-status — Portfolio Status: current positions, balances and P&L for all active trading bots.
- weather-forecast-edge — Weather Forecast Edge: compares GFS forecasts against Kalshi temperature-market strike prices using a calibrated normal CDF probability model.
- market-scan — Market Scan: scans Kalshi prediction markets for opportunities with configurable filters and scoring.
- oracle-picks — Oracle Trading Picks: browse the Weather Oracle strategy catalog, request live picks with tier-based access, view track record, or sign up for a buyer account.

## What a live call returned

A single anonymous message/send asking "What strategies do you offer?" returned a plain-text strategy catalog of six strategies — buycheapno, fade, high_edge, high_oracle, v11no (all "Risk: MEDIUM | Status: testing | Track Record: No live data yet") and weather ("Status: deprecated") — and the hint "Say 'picks' to get current trading picks."

## What is not published

- No web pages: the apex serves 405 on GET / and 404 on every other GET path; www.baconhollow.com does not resolve.
- No OpenAPI, GraphQL, AsyncAPI, MCP server, llms.txt, robots.txt or sitemap.
- No security.txt, OAuth/OIDC discovery, RFC 9728 protected-resource metadata or api-catalog.
- No pricing, terms, privacy policy, operator identity or contact. The a2aregistry.org record lists author "Unknown".
- No SDK or package on npm, PyPI or GitHub.
